# Screenshots

Presentation screenshots are added manually (they are not generated). Take them from the running
application (`docker compose up --build`, then http://localhost:5173) and save them here with
these exact names so the main README can display them:

| File | What to capture |
| --- | --- |
| `browse-items.png` | Browse Items page with search, filters and item cards (**added**) |
| `home.png` | Landing page with recently reported items |
| `lost-report.png` | Report Lost Item form |
| `found-report.png` | Report Found Item form |
| `ai-match.png` | An item page showing the Potential Match card and Match Score |
| `claim.png` | The ownership claim form / modal |
| `admin-dashboard.png` | `/admin` with statistics, pending reports and claims |
| `private-report.png` | A report marked 🔒 PRIVATE (for example in My Items) |
| `swagger.png` | Swagger UI at http://localhost:8000/docs |

After adding a file, open the root `README.md`, find its section under **Screenshots** and
uncomment the image line (remove `<!--` and `-->`).

Tip: do not include real personal data or passwords in screenshots.
